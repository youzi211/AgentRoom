# Colors — AgentRoom Design System

> 本文件详细定义 AgentRoom 的色彩系统，包括品牌色、中性色、语义色及其使用场景。
> 所有色值必须与 tokens.md 和 MASTER.md 保持一致。

---

```
  ├── 链接
  ├── 激活状态指示
  ├── 品牌 Logo
  └── 强调文本

#0F766E  ──── 品牌 Hover
  ├── 按钮 hover
  ├── 链接 hover
  └── 激活状态 hover

#CCFBF1  ──── 品牌软背景
  ├── 选中状态背景
  ├── 消息气泡（自己）
  ├── Badge 软背景
  └── 标签页激活背景
```

### Secondary: #14B8A6 (teal-500)

```
#14B8A6  ──── 辅助品牌色
  ├── 次要按钮
  ├── 装饰性元素
  └── 状态指示器
```

## 4. 色值对比

### 当前项目 vs 新规范

| 角色 | 当前值 | 新值 | 差异 |
|------|--------|------|------|
| 背景 | `#f6f7f4` | `#F8FAFC` | 轻微，从暖灰到冷灰 |
| 表面 | `#ffffff` | `#FFFFFF` | 无变化 |
| 主文字 | `#1f2933` | `#0F172A` | 加深，提高对比度 |
| 品牌色 | `#2f6657` | `#0D9488` | 变亮，更具现代感 |
| 品牌软 | `#e7f1ec` | `#CCFBF1` | 变亮 |
| 边框 | `#dde5dc` | `#E2E8F0` | 轻微 |

### 迁移策略

1. 先在 CSS 变量中更新色值
2. 然后更新 Mantine theme 的 teal 色板
3. 最后在组件中逐步替换硬编码的颜色

## 5. 使用规则

### 5.1 颜色使用优先级

1. 优先使用 Mantine 的 color props（如 `color="teal"`）
2. 其次使用 CSS 变量（如 `var(--brand)`）
3. 避免硬编码色值

### 5.2 对比度要求

- 正文文字 (`#0F172A`) 在白色背景上对比度: **12.6:1** ✅ WCAG AAA
- 次要文字 (`#475569`) 在白色背景上对比度: **5.8:1** ✅ WCAG AA
- 弱化文字 (`#94A3B8`) 在白色背景上对比度: **3.2:1** ⚠️ 仅用于辅助信息
- 品牌色 (`#0D9488`) 在白色背景上对比度: **3.8:1** ⚠️ 不适合小号正文

### 5.3 禁止

- 不使用 Mantine 默认色板以外的颜色
- 不在同一页面中使用超过 3 种语义色
- 不使用 `#000` 或 `#fff`（使用 `#0F172A` 和 `#F8FAFC` 替代）
- 不使用纯黑阴影
