# Page: RoomGateway — AgentRoom Design System

> 本文件定义 RoomGateway（房间入口页面）的 UI 规范。

---

## 1. 页面目标

- 根据房间状态和用户权限，路由到正确的页面表面
- 加载中: 显示确认状态
- 活跃房间: 路由到 ChatRoom
- 关闭房间: 路由到只读页面
- 归档房间: 显示拒绝访问
- 需要口令: 显示口令输入表单

---

## 2. 信息层级

### Loading 状态

```
1. 标题: "正在确认会议状态"
2. 描述: 解释正在检查什么
```

### Entry 状态（需要输入名称/口令）

```
1. 标题: "加入会议"
2. 房间 ID 显示
3. 名称输入
4. 口令输入（如需要）
5. 加入按钮
```

### Denied 状态

```
1. 标题: "会议已归档"
2. 描述: 说明不能访问的原因
3. 返回按钮
```

---

## 3. Layout

使用 Center 模式：

```
+--------------------------------------------------+
|  .workbench--center                               |
|  display: flex, justify-content: center,          |
|  align-items: center                              |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  Paper (withBorder, radius="md", shadow="sm") │ |
|  │  max-width: 520px                             │ |
|  │                                                │ |
|  │  ├── Eyebrow: "会议链接" / "只读限制"         │ |
|  │  ├── H1: 标题                                 │ |
|  │  ├── Body: 描述                               │ |
|  │  └── Button: 操作                             │ |
|  └──────────────────────────────────────────────┘ |
+--------------------------------------------------+
```

---

## 4. 核心组件

| 组件 | 规范 |
|------|------|
| 信息面板 | Paper, withBorder, radius="md", shadow="sm" |
| 标题 | H1 层级 |
| 描述 | Body 层级 |
| 表单 | 标准 Input + Button |
| 返回按钮 | Button, variant="light", color="teal" |

---

## 5. 状态

### Loading

- Paper 内显示标题 + 描述
- 无需 skeleton，文字足够

### Entry

- 表单包含名称输入和口令输入（如需要）
- 按钮: "加入会议"

### Denied

- 标题: "会议已归档"
- 描述: 说明原因
- 按钮: "返回入口"

### 404

- 路由到 NotFound 组件
- 标题: "页面不存在"
- 按钮: "返回首页"

---

## 6. Do / Don't

### Do

- 使用 Center 布局，让用户专注于当前操作
- 清晰的标题和描述，减少用户困惑
- 提供明确的返回操作

### Don't

- 不要在 Gateway 页面展示过多信息
- 不要让 loading 状态看起来像死机
- 不要使用复杂的布局
