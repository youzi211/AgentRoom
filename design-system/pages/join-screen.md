# Page: JoinScreen — AgentRoom Design System

> 本文件定义 JoinScreen（首页/创建+加入房间页面）的 UI 规范。

---

## 1. 页面目标

- 用户首次进入时理解 AgentRoom 是什么
- 创建新房间
- 加入已有房间
- 进入管理后台

---

## 2. 信息层级

```
1. 品牌标识（Logo + 名称）
2. Hero 标题（"开始一次协作会议"）
3. 能力展示（3-4 个特性卡片）
4. 创建房间（表单）
5. 加入房间（表单）
6. 管理后台入口（链接）
```

---

---

## 4. 核心组件

| 组件 | 规范 | 说明 |
|------|------|------|
| App Bar | 使用普通 header，不套 Paper | 品牌 + 导航 |
| Hero 标题 | H1 层级 | 页面主标题 |
| 特性卡片 | 2x2 网格，使用 Paper | 能力展示，可简化 |
| 表单 | 标准 Input + Button | 创建/加入房间 |
| Agent 选择 | Mantine Select, multiple, searchable | 选择参会 Agent |
| 协作策略 | SegmentedControl | 选择对话策略 |

---

## 5. Spacing

| 区域 | 间距 |
|------|------|
| 整体容器 padding | 24px |
| Hero 下方 | 32px |
| 特性卡片网格 | 16px gap |
| 表单内部 | 16px gap |
| 创建/加入区域间距 | 24px |

---

## 6. 状态

### Loading

- 创建房间按钮显示 loading 状态
- 表单禁用交互

### Empty

- 无 Agent 可选时显示提示
- 无最近房间时显示"暂无"

### Error

- 创建失败: Alert 在表单上方显示
- 加入失败: Alert 在表单上方显示
- 网络错误: 通用错误提示

---

## 7. 响应式

| 断点 | 调整 |
|------|------|
| mobile | 特性卡片 1 列，表单全宽 |
| tablet | 特性卡片 2 列 |
| desktop | 特性卡片 4 列 |

---

## 8. Do / Don't

### Do

- 保持 Hero 简洁，不要堆砌文字
- 特性卡片使用图标 + 标题 + 一句话描述
- 创建和加入房间的表单分开，清晰区分

### Don't

- 不要在首页展示过多信息
- 不要让特性卡片占据过多视觉权重
- 不要使用过大的 Hero 图片
- 不要让创建和加入房间的入口混淆
