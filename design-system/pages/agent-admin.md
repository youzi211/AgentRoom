# Page: AgentAdmin — AgentRoom Design System

> 本文件定义 AgentAdmin（Agent 管理页面）的 UI 规范。

---

## 1. 页面目标

- 浏览所有 Agent 配置
- 创建/编辑/删除 Agent
- 上传 Agent 知识文档
- 管理 Agent 角色模板

---

## 2. 信息层级

```
1. 页面标题: "Agent 管理"
2. Agent 列表
3. 编辑/创建 Agent 表单（Modal 或内联）
4. Agent 知识库面板
5. 角色模板管理
```

---

## 3. Layout

```
+--------------------------------------------------+
|  ┌──────────────────────────────────────────────┐ |
|  │  Header: "Agent 管理"  [+ 创建 Agent]        │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  Agent 列表 (卡片网格或列表)                 │ |
|  │  ├── Agent 卡片 1                            │ |
|  │  ├── Agent 卡片 2                            │ |
|  │  └── ...                                     │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  Modal: 编辑/创建 Agent                     │ |
|  │  ├── 名称 / 角色 / 描述                     │ |
|  │  ├── System Prompt (Textarea)                │ |
|  │  ├── 运行时选择 (Select)                     │ |
|  │  ├── 模型 Profile 绑定                      │ |
|  │  └── 保存 / 取消                            │ |
|  └──────────────────────────────────────────────┘ |
+--------------------------------------------------+
```

---

## 4. 核心组件

| 组件 | 规范 |
|------|------|
| Agent 卡片 | Paper, withBorder, radius="md" |
| 创建/编辑表单 | Modal 内表单 |
| 启用/禁用 | Mantine Switch |
| 删除 | Button, color="red", variant="light" |
| 知识库 | 嵌入 KnowledgePanel |
| 角色模板 | Collapse 展开/折叠 |

---

## 5. Spacing

| 区域 | 间距 |
|------|------|
| 卡片网格 gap | 16px |
| 卡片内边距 | 20px |
| 表单字段间距 | 16px |
| 操作按钮间距 | 8px |

---

## 6. 状态

### Loading

- 列表加载: skeleton 卡片
- 保存中: 按钮 loading

### Empty

- 无 Agent: "暂无 Agent，点击创建第一个 Agent"

### Error

- 保存失败: Modal 内 Alert
- 删除失败: 页面 Alert
