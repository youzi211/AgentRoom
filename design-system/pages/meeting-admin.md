# Page: MeetingAdmin — AgentRoom Design System

> 本文件定义 MeetingAdmin（会议管理页面）的 UI 规范。

---

## 1. 页面目标

- 浏览所有会议列表
- 按状态筛选（active / closed / archived）
- 查看会议详情
- 执行生命周期操作（归档/重新打开/恢复）

---

## 2. 信息层级

```
1. 页面标题: "会议管理"
2. 筛选: 状态标签页
3. 会议列表（表格）
4. 会议详情（点击展开或新区域）
```

---

## 3. Layout

```
+--------------------------------------------------+
|  ┌──────────────────────────────────────────────┐ |
|  │  Header: "会议管理"  [刷新按钮]              │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  Filter: [全部] [进行中] [已关闭] [已归档]   │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  Table                                       │ |
|  │  ├── 会议名 | 状态 | 创建时间 | 操作         │ |
|  │  ├── ...                                     │ |
|  │  └── ...                                     │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  或:                                                |
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │  MeetingRoomDetail (点击会议后展开)          │ |
|  │  ├── 会议信息                                │ |
|  │  ├── 参与者列表                              │ |
|  │  ├── 消息历史                                │ |
|  │  └── 操作按钮                                │ |
|  └──────────────────────────────────────────────┘ |
+--------------------------------------------------+
```

---

## 4. 核心组件

| 组件 | 规范 |
|------|------|
| 筛选 | Mantine SegmentedControl 或 Badge 组 |
| 表格 | Mantine Table，striped 或 row hover |
| 状态 Badge | Badge, variant="light", 颜色对应状态 |
| 操作按钮 | Button, variant="light", size="xs" |
| 详情面板 | 普通 div，不套 Paper |

---

## 5. Spacing

| 区域 | 间距 |
|------|------|
| 标题与筛选 | 16px |
| 筛选与表格 | 16px |
| 表格行内边距 | 12px 16px |
| 操作按钮间距 | 8px |

---

## 6. 状态

### Loading

- 初始加载: 表格 skeleton 行
- 刷新: 表格内容保持，显示加载指示

### Empty

- 无会议: "暂无会议记录"
- 筛选后无结果: "没有符合条件的会议"

### Error

- 加载失败: Alert + 重试按钮
- 操作失败: Alert + 错误信息

---

## 7. 响应式

| 断点 | 调整 |
|------|------|
| mobile | 表格变为卡片列表 |
| tablet | 表格保持，但操作列使用图标按钮 |
