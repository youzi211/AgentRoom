# API 参考\n\n> 本文档列出 AgentRoom 后端暴露的 HTTP API 路由。所有路由均在 /api 前缀下。\n\n---\n\n## 目录\n\n- [健康检查](#健康检查)\n- [管理鉴权](#管理鉴权)\n- [Agent 管理](#agent-管理)\n- [房间管理](#房间管理)\n- [消息历史](#消息历史)\n- [会议纪要](#会议纪要)\n- [知识库](#知识库)\n- [WebSocket](#websocket)\n- [房间状态说明](#房间状态说明)\n\n---\n\n## 健康检查\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/health | Go 进程存活检查 |\n| GET | /api/ready | MySQL 和 Agent Runtime 依赖就绪检查 |\n\n---\n\n## 管理鉴权\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/admin/verify | 验证 X-Admin-Key，用于管理控制台门禁 |\n\n需要 X-Admin-Key 请求头（当 ADMIN_API_KEY 已配置时）。\n\n---\n\n## Agent 管理\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/agents | 列出所有全局 Agent |\n| POST | /api/agents | 创建新 Agent |\n| PUT | /api/agents/:agentID | 更新 Agent |\n| DELETE | /api/agents/:agentID | 删除 Agent |\n| GET | /api/agents/:agentID/knowledge | 获取 Agent 知识库列表 |\n| POST | /api/agents/:agentID/knowledge | 上传 Agent 知识文档 |\n\n---\n\n## 房间管理\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| POST | /api/rooms | 创建新房间 |\n| GET | /api/rooms | （管理）列出房间，支持 ?status 和 ?limit/?offset 分页 |\n| GET | /api/rooms/:roomID | 获取房间详情 |\n| POST | /api/rooms/:roomID/archive | （管理）归档房间 |\n| POST | /api/rooms/:roomID/reopen | （管理）重新打开已关闭的房间 |\n| POST | /api/rooms/:roomID/restore | （管理）恢复已归档的房间 |\n| GET | /api/rooms/:roomID/activity | 获取 Agent 活动历史 |\n\n房间列表参数：\n- ?status=active|closed|archived|all\n- ?limit= 和 ?offset= 分页\n\n---\n\n## 消息历史\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/rooms/:roomID/messages | 分页消息历史，返回 { messages, hasMore, nextBefore } |\n\n参数：?limit= 和 ?before=（游标分页）\n\n---\n\n## 会议纪要\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| POST | /api/rooms/:roomID/minutes | 生成并持久化新版本的 AI 会议纪要 |\n| PUT | /api/rooms/:roomID/minutes | （管理）保存编辑后的纪要为新版本 |\n| GET | /api/rooms/:roomID/minutes/history | （管理）列出所有纪要版本 |\n| GET | /api/rooms/:roomID/minutes.md | 下载最新纪要 Markdown（404 当不存在时） |\n\n---\n\n## 知识库\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/rooms/:roomID/knowledge | 获取房间知识库列表 |\n| POST | /api/rooms/:roomID/knowledge | 上传房间知识文档 |\n| DELETE | /api/knowledge/:documentID | 删除知识文档 |\n\n---\n\n## WebSocket\n\n| 方法 | 路由 | 说明 |\n|------|------|------|\n| GET | /api/rooms/:roomID/ws?name=Alice | WebSocket 加入房间 |\n\n房间加入参数：?name= 用户名（必填）\n\n---\n\n## 房间状态说明\n\n| 状态 | 普通用户访问 | 管理员操作 |\n|------|-------------|-----------|\n| active | 加入 WebSocket、发言、转移所有权、关闭会议 | 所有操作 |\n| closed | 只读查看消息和纪要，不能加入 WebSocket | 可重新打开 |\n| archived | 不可访问 | 可查看和恢复为 closed |\n\n有效管理员密钥（X-Admin-Key）可绕过房间密码，用于管理操作。\n\n---\n\n## 相关文档\n\n- [部署指南](../deployment/)\n- [开发指南](../development/)\n- [架构文档](../architecture/)\n
