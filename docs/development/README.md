# 开发指南\n\n> 本文档提供 AgentRoom 的本地开发环境搭建、测试命令和代码规范。\n\n---\n\n## 目录\n\n- [前置条件](#前置条件)\n- [本地开发环境搭建](#本地开发环境搭建)\n- [测试命令](#测试命令)\n- [代码规范](#代码规范)\n- [提交规范](#提交规范)\n\n---\n\n## 前置条件\n\n- Go 1.22+\n- Node.js 18+\n- npm 9+\n- MySQL 8+\n- Python 3.11+ 和 uv（运行 DeepAgent 时需要）\n\n---\n\n## 本地开发环境搭建\n\n### 1. 准备环境变量\n\n`powershell\nCopy-Item .env.example .env\n`\n\n编辑 .env，设置 MYSQL_DSN 指向本地 MySQL 8 数据库：\n\n`nv\nMYSQL_DSN=root:password@tcp(127.0.0.1:3306)/agentroom?charset=utf8mb4&parseTime=True&loc=Local\n`\n\n### 2. 启动后端\n\n`powershell\ngo -C backend run ./cmd/server\n`\n\n### 3. 启动前端（新终端）\n\n`powershell\nnpm --prefix frontend run dev\n`\n\n### 4. 可选：启动 DeepAgent\n\n`powershell\ncd deepagent\nuv sync\nCopy-Item .env.example .env\n# 编辑 .env 填入模型和搜索凭据\nuv run agent-runtime\n`\n\n---\n\n## 测试命令\n\n### Go 后端测试\n\n`powershell\n# 全部测试\ngo -C backend test ./...\n\n# 静态检查\ngo -C backend vet ./...\n\n# 构建验证\ngo -C backend build ./cmd/server\n`\n\n### Python 测试\n\n`powershell\ncd deepagent\nuv run pytest\n`\n\n### 前端测试\n\n`powershell\n# 构建验证\nnpm --prefix frontend run build\n\n# 单前端测试文件\nnode --test frontend/src/api/roomClient.test.mjs\n`\n\n### Docker Compose 配置验证\n\n`powershell\ndocker compose config\n`\n\n---\n\n## 代码规范\n\n### Go\n\n- 保持 gofmt 格式\n- 导出类型使用 PascalCase，内部使用 camelCase\n- 遵循六条铁律：职责清晰、依赖单向、核心业务不依赖具体技术、接口小而精、并发资源错误有边界、架构服务于变化\n\n### 前端\n\n- 组件文件使用 PascalCase（如 ChatRoom.jsx）\n- 工具模块使用 camelCase\n- 2 空格缩进、单引号、无分号\n\n### 架构原则\n\n1. **组合根明确** — backend/cmd/server/main.go 是唯一基础设施装配入口\n2. **持久化与实时状态分离** — MySQL 保存业务事实，进程内存保存 WebSocket 连接和房间缓存\n3. **全局 Agent 与房间 Agent 分离** — 修改全局 Agent 只影响新房间\n4. **/api/* 是规范协议面** — 新开发只面向 /api/*\n\n---\n\n## 提交规范\n\n### 分支命名\n\n`	ext\ncodex/feat/功能名\ncodex/fix/修复名\ncodex/refactor/重构名\n`\n\n### 提交消息\n\n使用 Conventional Commits 规范，中文描述：\n\n`\nfeat: 添加用户注册功能\nfix: 修复支付回调错误\nrefactor: 重构房间状态机\ndocs: 更新 API 文档\nchore: 更新依赖\n`\n\n### 提交前检查\n\n- 后端测试通过：go -C backend test ./...\n- 前端构建通过：npm --prefix frontend run build\n- 排除本地配置文件：git add -A -- :!.mcp.json\n\n---\n\n## 相关文档\n\n- [架构文档](../architecture/)\n- [API 参考](../api/)\n- [部署指南](../deployment/)\n
